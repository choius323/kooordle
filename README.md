# 한글 워들 "오늘의 단어"

자모 단위로 정답 단어를 맞히는 한글 워들 게임입니다.
출제자가 만든 문제 링크를 카톡으로 공유해서 함께 풉니다.

---

## 1. 게임 규칙

### 기본
- 정답 단어를 **자모 단위**로 맞힙니다. 예) 라이벌 → ㄹ ㅏ ㅇ ㅣ ㅂ ㅓ ㄹ (7칸)
- 칸 수(자모 수)는 문제마다 다릅니다.
- 기회는 **5번**입니다.
- 정답 단어와 입력하는 단어 모두 **사전(우리말샘)에 있는 단어**만 쓸 수 있습니다.
- 사전을 불러오지 못하면 "사전 없이 진행해요"가 뜨고, 아무 자모 조합이나 제출할 수 있습니다.

### 자모 나누기 규칙
키보드에 ㅐ, ㅔ, 쌍자음이 없으므로 아래처럼 나눠서 입력합니다.

| 구분 | 나누기 |
|---|---|
| 모음 | ㅐ=ㅏㅣ, ㅒ=ㅑㅣ, ㅔ=ㅓㅣ, ㅖ=ㅕㅣ, ㅘ=ㅗㅏ, ㅙ=ㅗㅏㅣ, ㅚ=ㅗㅣ, ㅝ=ㅜㅓ, ㅞ=ㅜㅓㅣ, ㅟ=ㅜㅣ, ㅢ=ㅡㅣ |
| 쌍자음 | ㄲ=ㄱㄱ, ㄸ=ㄷㄷ, ㅃ=ㅂㅂ, ㅆ=ㅅㅅ, ㅉ=ㅈㅈ |
| 겹받침 | ㄳ=ㄱㅅ, ㄵ=ㄴㅈ, ㄶ=ㄴㅎ, ㄺ=ㄹㄱ, ㄻ=ㄹㅁ, ㄼ=ㄹㅂ, ㄽ=ㄹㅅ, ㄾ=ㄹㅌ, ㄿ=ㄹㅍ, ㅀ=ㄹㅎ, ㅄ=ㅂㅅ |

예) 봉황 → ㅂ ㅗ ㅇ ㅎ ㅗ ㅏ ㅇ

### 색의 의미
| 색 | 의미 |
|---|---|
| 🟩 초록 | 자모와 자리가 모두 맞음 |
| 🟨 노랑 | 정답에 있지만 자리가 다름 |
| ⬜ 회색 | 정답에 없음 |

- 같은 자모가 여러 번 나오면 정답에 있는 개수만큼만 색을 칠합니다. 초록을 먼저 칠하고, 남은 개수만큼 노랑을 칠합니다.
- 키보드는 가장 좋은 결과의 색으로 칠합니다. 우선순위는 초록 > 노랑 > 회색입니다.
- 키보드에서 '정답에 없음' 키는 회색 대신 **흐리게** 표시됩니다. 라이트·다크 모드 모두 같습니다.
- PC에서는 영문 자판 그대로 입력해도 됩니다. 예를 들어 `r`은 ㄱ, `k`는 ㅏ로 입력됩니다.

### 출제와 공유
- 사이트 주소만 열면 **출제 화면**이 나옵니다. 단어와 날짜를 넣으면 문제 링크(`...?q=코드`)가 만들어집니다.
- **랜덤 문제 만들기** 버튼을 누르면 `answers/` 목록(25,750단어)에서 단어를 무작위로 골라 링크를 만듭니다.
  - **랜덤 출제 자모 수**에서 4~15개 중 하나를 고를 수 있습니다. '아무거나'로 두면 전체 목록에서 뽑습니다.
  - 출제자도 같이 풀 수 있도록 단어는 화면에 보여 주지 않습니다.
  - 같은 브라우저에서 랜덤으로 낸 단어는 기록해 두고 다시 뽑지 않습니다. 고른 자모 수의 단어를 다 쓰면 그 자모 수만 처음부터 다시 뽑습니다. 기록은 브라우저마다 따로 저장되므로, 다른 기기에서 출제하면 겹칠 수 있습니다.
- 출제할 때도 **사전에 있는 단어만** 쓸 수 있습니다. 사전을 불러오지 못했거나, 자모 수가 사전 범위(4~15개)를 벗어나면 제한 없이 출제됩니다.
- 문제 화면에서 상단의 `‹` 버튼이나 "오늘의 단어" 제목을 누르면 출제 화면으로 돌아갑니다.
- 코드 구조: `[자모 수 1자][날짜 2자][글자마다 3자][검증 1자]`. 영문 대소문자와 숫자를 쓰는 62진법입니다.
- 다 풀면 **결과 공유하기** 버튼으로 🟩🟨⬜ 결과를 카톡에 붙여 넣을 수 있습니다.
- 진행 기록은 브라우저에 저장되므로, 같은 링크를 다시 열면 이어서 풀 수 있습니다.
- 인코딩은 링크만 보고 정답을 알 수 없게 가리는 정도입니다. 코드를 분석하면 풀 수 있습니다.

## 2. 파일 구성

```
kooordle/
├─ index.html   게임 화면 + 출제 화면 (파일 하나로 동작)
├─ build.py          사전 txt를 만드는 파이썬 스크립트
├─ build_answers.py  랜덤 출제용 정답 목록을 만드는 파이썬 스크립트
├─ README.md
├─ dict/             자모 수별 사전 (4.txt ~ 15.txt) – 입력 검사용
└─ answers/          자모 수별 정답 후보 (4.txt ~ 15.txt) – 랜덤 출제용
```

- `dict/7.txt`에는 자모 7개짜리 단어가 한 줄에 하나씩 들어 있습니다.
- 게임은 문제의 자모 수에 맞는 파일 하나만 불러옵니다.

## 3. 사전 만들기 (build.py)

### 순서
1. 우리말샘(opendict.korean.go.kr)에 로그인하고 **내 정보 관리 → 사전 내려받기**에서 **JSON** 형식으로 전체 사전을 받습니다.
2. 압축을 풀면 `1621592_50000.json`처럼 여러 개의 json 파일이 나옵니다.
3. 그 폴더 옆에 `build.py`를 두고 실행합니다.
   ```powershell
   python build.py "압축 푼 폴더 이름"
   ```
4. `dict` 폴더에 `4.txt` ~ `15.txt` 파일이 생깁니다.

### 걸러내는 기준
- 품사가 **명사**이고 단위가 **어휘**인 단어만 남깁니다. 구, 관용구, 속담은 뺍니다.
- **방언, 북한어, 옛말**은 뺍니다. 뜻풀이마다 붙은 구분(`type`) 값으로 판단합니다.
  - 같은 단어에 일반어 명사 뜻이 하나라도 있으면 남깁니다.
  - 방언·북한어·옛말 뜻만 있는 단어는 빠집니다. 예) 정구지(방언), 얼음보숭이·손전화(북한어)
- **2~6글자** 단어만 남깁니다.
- 표제어에 붙은 `-`, `^`, 숫자는 자동으로 지웁니다.
- 기준을 바꾸려면 `build.py` 위쪽의 설정 부분(`POS`, `EXCLUDE_TYPE`, `SYL`, `JAMO`)을 고칩니다.

### 참고
- 원본 json 파일(약 1.9GB)은 GitHub에 올리지 않습니다.
- 구조를 확인하고 싶으면 `python build.py "폴더" --peek`로 첫 단어의 전체 내용을 볼 수 있습니다.
- PowerShell에서 json의 한글이 깨지면 `Get-Content 파일 -Encoding UTF8`로 엽니다.

## 3-1. 랜덤 출제용 정답 목록 만들기 (build_answers.py)

`dict/`에는 전문어, 지명, 인명까지 32만 단어가 있어 정답으로 쓰기엔 어려운 단어가 많습니다.
그래서 학습자용 사전인 **한국어기초사전**에서 자주 쓰는 명사만 골라 `answers/`를 따로 만듭니다.

### 순서
1. 한국어기초사전(krdict.korean.go.kr)에서 **JSON** 형식으로 전체 사전을 내려받아 압축을 풉니다.
2. `build.py`로 `dict/`를 먼저 만들어 둡니다. 정답이 우리말샘 사전에 있는지 확인할 때 씁니다.
3. 실행합니다.
   ```powershell
   python build_answers.py "압축 푼 폴더 이름"
   ```
4. `answers` 폴더에 `4.txt` ~ `15.txt` 파일이 생깁니다.

### 걸러내는 기준
- 단위가 **단어**이고 품사가 **명사**인 것만 남깁니다.
- 어휘 등급이 **초급·중급·고급**인 단어만 남깁니다. 등급이 '없음'인 단어에는 고유명사(낙동강, 레바논)와 비표준 표기(아지랭이, 부페)가 많아 뺍니다.
- **2~6글자**, 자모 **4~15개**인 단어만 남깁니다.
- **우리말샘 사전(`dict/`)에 있는 단어만** 남깁니다.
- 기준을 바꾸려면 `build_answers.py` 위쪽의 설정 부분(`POS`, `LEVELS`, `SYL`, `JAMO`)을 고칩니다.

## 4. GitHub Pages에 올리기

1. GitHub에서 **New repository**로 저장소를 만듭니다. 공개 범위는 **Public**입니다. 무료 계정은 Public이어야 Pages를 쓸 수 있습니다.
2. **Add file → Upload files**로 `index.html`, `build.py`, `build_answers.py`, `README.md`, `dict` 폴더, `answers` 폴더를 올리고 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source는 `Deploy from a branch`, Branch는 `main`, 폴더는 `/ (root)`로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 열립니다.

### 동작 확인
- 사전에 있는 단어를 입력했을 때 채점되면 정상입니다.
- 엉터리 자모(예: ㄱㄱㄱㄱㄱ)를 입력했을 때 "사전에 없는 단어예요"가 뜨면 사전이 잘 연결된 것입니다.
- "사전 없이 진행해요"가 뜨면 `dict` 폴더 위치나 파일 이름을 확인합니다.
- 내 PC에서 `index.html`을 더블클릭해 열면 사전을 불러올 수 없어 사전 검사 없이 동작합니다. 사전까지 확인하려면 GitHub 주소로 열어야 합니다.
- 광고 차단 앱(유니콘 등)은 사이트를 허용해도 입력이 느려질 수 있습니다. 느리면 Safari 설정 → 확장 프로그램에서 이 사이트만 '거부'로 바꿉니다.

### 주의
- 저장소 이름을 바꾸면 주소도 바뀝니다. 이미 공유한 문제 링크는 다시 만들어야 합니다.
- 웹 업로드는 파일 하나당 25MB까지입니다.
